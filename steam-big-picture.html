The non-Steam gap

Big Picture is great. Imported games are the exception.

Steam treats its own games like first-class citizens: cloud saves, achievements, updates, artwork, and a controller profile that just works. Add a game from another store and most of that stops. Couchfront can fill in the shortcut and artwork, but it cannot replace the store client. Here is what is missing and what can be automated.

What a "non-Steam game" actually is

When you use Add a Non-Steam Game, Steam writes an entry into shortcuts.vdf in your Steam account's userdata folder. That entry holds a name, an executable path, a start directory, maybe an icon, and nothing else. Steam derives the shortcut's AppID from a CRC32 hash of the entry, which is also how it decides which artwork files belong to it.

There is no store contract behind that entry. No purchase record, no manifest, no update channel, no cloud storage. It is a launcher for a file. That's why the missing features below aren't bugs Steam intends to fix: they're outside what a shortcut can be.

What you don't get

  • Artwork. No capsule, hero, logo, or icon is fetched. In Big Picture your imported game shows as a plain tile with a tiny icon, which looks wrong on a TV. All four images have to be added by hand, in the desktop client, with the correct AppID-style filenames.
  • Store metadata. No description, screenshots, release date, reviews, DLC list, or news feed. The game's page in your library is essentially empty.
  • Cloud saves. Steam Cloud covers Steam games. Your Epic or GOG save lives where that store puts it, and Steam neither backs it up nor restores it. Couchfront can mirror that folder to your own Google Drive and restore it, but that is not Steam Cloud: there is no automatic per-account Steam integration.
  • Achievements and progress tracking. None. Playtime is the one thing Steam does count, and only while the game is launched through the shortcut.
  • Updates and patches. Steam won't patch a game it didn't install. If the store's client isn't running, the game may launch at an old version.
  • Install management. No uninstall, no verify files, no move-to-another-drive, no download queue. That all stays in the store's own client.
  • Family sharing and Remote Play Together. Both are tied to Steam ownership; shortcuts don't qualify.
  • Steam Input and the overlay, reliably. The overlay usually hooks a shortcut, but it isn't guaranteed through a store launcher that spawns the real game as a child process, and some anti-cheat setups block it outright. There's no curated controller config either, so you're building one yourself or falling back on whatever the store's launcher offers.
  • Any awareness the game is gone. Uninstall a game outside Steam and the tile stays, pointing at a path that no longer exists. The artwork files stay too, orphaned in the grid folder.
  • Portability between PCs or accounts. Shortcuts are stored per Steam account with no cloud sync. Sign into another account and they vanish; set up a second PC and you add all of them again.

The part that doesn't scale

None of the above is fatal for one game. The problem is volume. Forty imported games means forty manual entries, each with the right executable and start directory, plus up to four artwork files each. That is around 160 images, named to match Steam's internal AppID for that shortcut, downloaded from a third-party site by hand.

Then a game updates and moves its executable. Or you rename a shortcut, which changes its AppID, which makes every artwork file stop matching. Or you reinstall Steam and rebuild the list from scratch. The maintenance is the real cost, not the initial setup.

What still stays Steam's job

This is worth stating plainly, because a launcher page that pretends otherwise is lying to you:

  • Purchases stay in the store that owns the game. Couchfront can download and install from sources you configure, but it is not a storefront.
  • Achievements still don't exist for imported titles. Cloud saves are yours to mirror: point Couchfront at the save folder (auto-detected from Ludusavi) and it syncs it to your own Google Drive.
  • Updates still come from the store's updater. Keeping that client installed and occasionally signed in remains necessary.
  • Steam Input profiles are still yours to configure per game. The app can hand Steam a correct shortcut, not a better controller layout.
  • Occasional per-game fixes still need a human: a weird start directory, an extra launch argument, or a game that insists on its own launcher splash. The heuristics are good, not psychic.
The short version

Steam will never manage a game it did not sell you. Couchfront can keep the shortcut and artwork accurate so the game still looks right in your library, and it can mirror the save folder to your own Google Drive. It cannot add Steam Cloud, achievements, or updates.

Common questions

Why is my non-Steam game a blank tile in Big Picture?

Because Steam never fetched artwork for it. Big Picture's grid reads capsule images from Steam's userdata grid folder, named after the shortcut's AppID. Without those files there's nothing to show, so you get a plain tile and the shortcut icon.

Does Steam track playtime for non-Steam games?

Yes. While the game is launched through the shortcut, Steam counts the session just like a native game. That's the one library feature that does carry over. Achievements and store data do not; Couchfront can sync the save folder to your own Google Drive.

Can Steam update or uninstall an imported game?

No. Steam has no manifest for it, so there's nothing to patch, verify, or remove. Updates come from the store's client. Uninstalling means using that client or deleting the folder, after which the shortcut itself lingers until something cleans it up.

Why do my shortcuts disappear or lose their artwork?

Shortcuts live per Steam account and aren't cloud-synced, so a different account sees an empty list and a new PC needs them re-added. Artwork also stops matching if a shortcut is renamed, because the AppID is derived from the shortcut's details.

Do I need to stop using the other launchers?

No, and you can't. The games need their clients installed. You just stop browsing and launching through them. See why this exists for what that buys you.
